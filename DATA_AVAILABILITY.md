# Data Availability Statement

## Public repository

https://github.com/Julians30/geometric-invariance-bean-rice

## Manuscript wording — AgriEngineering (MDPI)

> The Dry Bean dataset is publicly available from the UCI Machine Learning Repository (DOI: 10.24432/C50S4B). The 9,200-record INIAP Rice morphometric feature table, frozen training/calibration/test assignments, feature-level analysis code, numerical results, and SHA-256 integrity manifests are publicly available in the project repository: https://github.com/Julians30/geometric-invariance-bean-rice. These materials support reproducibility of the statistical and machine-learning analyses based on morphometric descriptors. Original INIAP Rice grain images, segmentation masks, and acquisition files are not redistributed as part of this repository.

## Scope and evidence

The repository includes the frozen tables and split manifests, source attribution, machine-readable main and supplementary tables, and analysis notebooks. A record-level 2025/2026 acquisition-provenance and prior-study-overlap mapping is now publicly available at [`reviewer_round_2026_10/NB16/NB16_10_manifest_procedencia_usado.csv`](reviewer_round_2026_10/NB16/NB16_10_manifest_procedencia_usado.csv). NB16–NB18 reviewer tables and source notebooks are archived separately from the original frozen evidence. The feature-level release does not provide original photos, full acquisition metadata or upstream segmentation scripts.

The repository does not reproduce upstream acquisition and segmentation; it also does not claim a separate archival DOI. Dry Bean attribution and rights are documented independently from reuse terms for the original INIAP Rice analytical table.
