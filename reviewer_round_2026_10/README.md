## Identifiers, denominators and protocol

- Dry Bean: **13,611 grains**, seven classes; **136 records in 68 exact duplicate groups** in the whole dataset. Frozen train/calibration/test row counts: 8,161/2,725/2,725.
- INIAP Rice: **9,200 grains**, INIAP-11 3,000; INIAP-12 4,000; INIAP-20 2,200. Frozen counts: 5,520/1,840/1,840. The available INIAP table contained no exact duplicate rows in the audited variables.
- The INIAP acquisitions are described as **multiple dates during 2025 and 2026**, not a single session; **2,400** records overlap with a previous study and **6,800** are additional records. The [NB16 record-level campaign/overlap mapping](NB16/NB16_10_manifest_procedencia_usado.csv) reports *year-level source labels only*, not independently verified production lot IDs, original photos, or per-image EXIF validation. This analysis cannot be described as future-campaign-held-out or cross-device validation.
- R2 contains six operational measured-core descriptors: area, perimeter, major/minor axis, convex area and **dimensionless EXTENT**; it omits **ECCENTRICITY**, redundant with the two axes.
- Dry Bean **R3-C** has eight native dimensionless columns; INIAP Rice **R3-NR** has the engineered five-descriptor invariant basis. Harmonized **R3-5** uses the same five descriptors (*aspect ratio, extent, solidity, circularity, ellipse fill*) in both datasets; **R4-5** adds log(pixel area). R3-5/R4-5 are not interchangeable with the original R3-C/R4-C specification.
- Original selected test macro-F1: Dry Bean **0.936605** (R1, RBF-SVM) and INIAP Rice **0.981165** (R4-NR, RBF-SVM). In the separately aligned representation refit the Dry Bean R1 macro-F1 is **0.935440**, and rice R1 is **0.977587**. These numbers come from different model/evaluation layers and should not be silently merged.
- Independent calibration sensitivity divides the frozen calibration partition by duplicate group into **40% temperature fitting / 30% selective thresholds / 30% conformal quantiles**. This is distinct from the original calibration procedure.
- Primary numerical equivalence margin **±0.01 macro-F1**; post hoc **±0.005** sensitivity is exploratory, not a cost-derived agricultural tolerance. In NB18, Dry Bean R1–R4-5 has grouped-bootstrap 90% interval [−0.003184, 0.004231], which fits ±0.005, while R1–R4-C has [−0.001058, 0.006205], which does not. Do not interchange these labels.
- The Cammeo–Osmancik **3,810-grain** comparison fits a new model within that separate dataset. It is a *representation-effect reference replication*, not transfer of an INIAP-trained model and not independent INIAP production-lot validation.

## Reproduction and technical notes

Source notebooks are retained in their original order with all **execution outputs/counters cleared**. Some code uses a Google Colab/Drive-relative directory `Grain_Robustness_Q1` and requires path adaptation and access to its declared frozen input archives for re-execution. These 26 CSV outputs are the exported numerical evidence; publishing an output does not mean that every notebook was independently executed in a clean GitHub CI environment. No upstream grain photographs, masks, or image-acquisition/segmentation scripts are included.
