# Third-party data attribution — Dry Bean

The **Dry Bean Dataset** used in this study is a public third-party benchmark and is **not owned by the manuscript authors**.

## Source

- Dataset: Dry Bean
- Creators: Murat Koklu and Ilker Ali Ozkan
- Repository: UCI Machine Learning Repository
- Records: 13,611
- Classes: 7
- Native morphometric features: 16
- DOI: `10.24432/C50S4B`
- License reported by UCI: Creative Commons Attribution 4.0 International (CC BY 4.0)

## Associated publication

Koklu, M.; Ozkan, I.A. *Multiclass classification of dry beans using computer vision and machine learning techniques*. Computers and Electronics in Agriculture, 2020, 174, 105507. https://doi.org/10.1016/j.compag.2020.105507

## Repository use

Any frozen copy included in this project exists only to preserve the exact analytical input and split assignments used in the manuscript. Its inclusion does not transfer ownership and must not be described as an author-generated dataset.

The original creators/source must remain attributed in any future public release or redistribution permitted by the source license.
