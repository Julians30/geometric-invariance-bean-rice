# Data

This directory is reserved exclusively for the **morphometric feature tables** used in the manuscript.

## Files to include

- `dry_bean_frozen_v1.csv`
- `iniap_rice_frozen_v1.csv`
- `data_dictionary.csv`

## INIAP Rice restriction

The INIAP Rice contribution is limited to the derived morphometric table used for analysis. **Do not upload original grain images, segmentation masks, image-acquisition files, or other raw visual materials.**

The analytical variables are expressed in image-space pixels, squared pixels, or as dimensionless shape descriptors, depending on the variable.

## Reproducibility note

The frozen datasets should be uploaded without modification so that their SHA-256 values remain consistent with the integrity manifests generated during the study.
