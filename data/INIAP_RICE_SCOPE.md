# INIAP Rice morphometric data — release scope

The **INIAP Rice dataset is original research data generated within the authors' research and is not a third-party public benchmark**.

## Analytical dataset used in this manuscript

- Records: **9,200**
- Varieties/classes: **INIAP-11, INIAP-12, and INIAP-20**
- Released analytical material: **numerical morphometric feature table only**
- Measurement domain: **image space**
- Linear descriptors: **pixels**
- Area-related descriptors: **squared pixels**
- Shape descriptors: dimensionless where applicable

The frozen feature-level table used by the analysis contains the morphometric measurements and technical identifiers required for the leakage-safe analytical workflow.

## Explicitly excluded from this article repository

The following assets are **not part of the release package**:

- original grain images;
- segmentation masks;
- raw image-acquisition files;
- unreleased visual material;
- image-acquisition and segmentation assets belonging to the ongoing doctoral research programme.

This exclusion is intentional. The manuscript evaluates classification and geometric-invariance questions from extracted morphometric descriptors; it does not claim to release or reproduce the upstream image-acquisition and segmentation stages.

## Reuse status

This repository is public and includes the derived INIAP Rice numerical morphometric table. Public access alone does not grant unrestricted reuse rights for the author-generated INIAP Rice table; no separate public reuse license has been specified in this notice.
