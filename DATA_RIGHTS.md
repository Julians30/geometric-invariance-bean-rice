# Data provenance, ownership, and reuse status

This repository contains analytical materials derived from **two datasets with different provenance and rights status**. The distinction is intentional and must be preserved in any future public release.

## Dry Bean Dataset — third-party public benchmark

The Dry Bean Dataset is **not owned by the authors of this repository**. It is a public benchmark distributed by the UCI Machine Learning Repository and attributed to Murat Koklu and Ilker Ali Ozkan.

- Records: 13,611
- Classes: 7
- Native morphometric features: 16
- UCI DOI: `10.24432/C50S4B`
- UCI license: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Associated publication: Koklu, M.; Ozkan, I.A. *Multiclass classification of dry beans using computer vision and machine learning techniques*. Computers and Electronics in Agriculture, 2020, 174, 105507. https://doi.org/10.1016/j.compag.2020.105507

Any redistributed analytical copy must retain attribution to the original Dry Bean creators/source and must not be described as an original dataset of the manuscript authors.

## INIAP Rice morphometric dataset — original research dataset

The INIAP Rice morphometric dataset used in this manuscript is an **original dataset generated within the authors' research**.

- Records: 9,200
- Varieties: INIAP-11 (3,000), INIAP-12 (4,000), INIAP-20 (2,200)
- Released scope: numerical morphometric feature table only
- Linear measurements: image-space pixels
- Area-related measurements: squared pixels
- Shape descriptors: dimensionless where applicable

The original grain images, segmentation masks, and complete image-acquisition/image-processing materials are **not part of this repository**. They form part of an ongoing doctoral research programme and are not released with this manuscript.

### Current reuse status of INIAP Rice data

This repository is private during manuscript preparation. **No separate public reuse license for the INIAP Rice morphometric table is granted by this file at this stage.** Reuse terms for the authors' original INIAP Rice morphometric data should be specified explicitly at the time of public release, consistent with the publication and doctoral-research plan.

## Repository code and documentation

A repository-wide software/documentation license has not been assigned automatically because the data components have different provenance and rights status. Licensing of code can be defined separately from data before public release.
