# Analysis Notebooks

This directory is reserved for the reproducible notebooks supporting the feature-level analyses reported in the manuscript.

Planned sequence:

1. Data audit and freeze.
2. Redundancy and representation construction.
3. Frozen partition generation and validation.
4. Training-only model selection.
5. Final fitting, calibration, and baseline testing.
6. Paired statistical inference.
7. Selective classification.
8. Conformal prediction.
9. Ablation and interpretability analyses.
10. Measurement and scale-sensitivity analyses.
11. Manuscript tables and figures.
12. Reviewer-driven reanalysis.
13. Final freeze and reconciliation.

Only notebooks required to reproduce analyses from the released morphometric feature tables belong here. Image acquisition and segmentation notebooks are outside the scope of this repository.
