# Documentation index

This directory contains manuscript-facing documentation that connects internal analytical asset names to the scientific reporting used in the article.

- [`MANUSCRIPT_ASSET_CROSSWALK.md`](MANUSCRIPT_ASSET_CROSSWALK.md) — maps methods, main tables, supplementary analyses, and high-value claims to their authoritative repository assets.
- [`MANUSCRIPT_LABEL_MAPPING.md`](MANUSCRIPT_LABEL_MAPPING.md) — maps historical internal representation names to the dataset-specific scientific labels used in the manuscript.

For data provenance and release rights, see `../DATA_RIGHTS.md`, `../data/THIRD_PARTY_ATTRIBUTION.md`, and `../data/INIAP_RICE_SCOPE.md`.

For the frozen analytical protocol and source hierarchy, see `../REPRODUCIBILITY.md` and `../notebooks/INDEX.md`.
